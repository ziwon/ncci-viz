# NCCL Lab visual system

Direction: scientific instrument console. A fixed topology viewport, precise transport notation, and a synchronized execution timeline support engineering investigation. Graph geometry is the main visual material, not decoration.

Neutral charcoal surfaces separate the page, diagram, panels, and controls. Off-white headings and gray secondary text keep the surrounding interface quiet. Pale lime identifies primary actions, selection, focus, and reduction transfers; cyan identifies gather and broadcast transfers. Transfer legends follow the active phase. Completed timeline steps use dark phase-colored fills with light numerals; the current step has a neutral outline. Distinct subdued chunk colors remain independent of interface colors. Warm colors identify warnings and errors.

Shared surface, text, border, and phase tokens live in `src/styles.css`. Controls and logical links have stronger borders than decorative separators. Thin neutral separators, minimal elevation, and compact controls preserve the instrument-console layout. Sans-serif interface; monospace only for addresses, code, counters, and computed values.

Composition: persistent operation rail, context header, configuration strip, topology and inspector, playback timeline, detailed data tabs. Mobile stacks these in reading order; the topology retains a usable minimum canvas. Respect reduced motion. Keyboard focus is clearly lime. All estimates identify the model and its assumptions.
